# ML Course Projects

This repository contains my implementations and project work. It covers a variety of machine learning and deep learning topics, including practical projects and model deployments.

---

## 📚 Contents

- **Crop_Recommendation_System:** A system to recommend crops based on environmental data.
- **DL:** Deep Learning notes, experiments, and assignments.
- **DL_MNIST_Fashion_Streamlit:** Streamlit app for Fashion MNIST classification.
- **Deploy:** Code and documentation for deployed ML models.
- **Init:** Initial project setups and testing.
- **Model_As_API:** Demonstrations of serving models via APIs.
- **Models:** Trained model files and checkpoints.
- **Multiple_Disease_Prediction_System:** Predicts multiple diseases using ML techniques.
- **Music_Genre_Classification_system:** Classifies music files into genres.
- **Plant_Disease_Detection_System:** Detects plant diseases from images.
- **Projects:** Additional, assorted machine learning projects.
